# Data Source

The files in this directory (`db.json`, `tasks.json`, `policy.md`) are derived
from the **airline domain** of the τ²-bench benchmark by Sierra Research.

- Project: τ-Bench / τ²-Bench
- Repository: https://github.com/sierra-research/tau2-bench
- Paper: https://arxiv.org/abs/2506.07982
- License: MIT (Copyright (c) 2025 Sierra Research)
